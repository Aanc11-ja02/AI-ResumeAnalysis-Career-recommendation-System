# AI-Based Resume Analysis and Career Recommendation System

## 📌 About the Project

The AI-Based Resume Analysis and Career Recommendation System is a web-based application designed to analyze a candidate's resume and provide personalized career recommendations.

The system uses Natural Language Processing (NLP) and Machine Learning techniques to extract relevant information from resumes, identify skills, analyze the candidate's profile, and match it with suitable career roles.

The main goal of the project is to help students and job seekers understand their current skill profile, identify skill gaps, and discover suitable career opportunities.

## 🎯 Objectives

- Analyze resumes automatically.
- Extract relevant skills, education, and experience.
- Identify the candidate's skill profile.
- Recommend suitable career roles.
- Calculate the match between candidate skills and career requirements.
- Identify skill gaps.
- Provide suggestions for career improvement.

## 🚀 Key Features

- Resume upload in PDF/DOCX format
- Automatic resume text extraction
- NLP-based skill extraction
- Resume profile analysis
- Career-role matching
- Personalized career recommendations
- Skill-gap identification
- Simple and user-friendly interface
- No mandatory user sign-in
